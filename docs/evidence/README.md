# Evidence archive

Last reviewed: 2026-08-25

Files in this directory are dated experiment records. Their observations,
commands and conclusions describe the named checkpoint and are not rewritten
to look like the final result. A later experiment can supersede an earlier
hypothesis without making the earlier evidence invalid.

Use [the current status matrix](../status.md) for present support claims and
[the roadmap](../roadmap.md) for remaining work. The latest cross-subsystem
checkpoint is [the package-complete Alpha 5 runtime](2026-08-25-package-complete-runtime.md).

Records whose title or final gate is actively misleading after a later result
carry an explicit supersession banner linking to the replacement evidence.
Release validation files remain immutable descriptions of their exact assets.
