# v0.1.0-alpha.3 source-complete release

Alpha 3 replaces Alpha 2 without changing its binary payload content. The
replacement was required because Alpha 2's rootfs contained locally built
libcamera `r12`, while its tag omitted patches `0008`, `0009` and `0010`.

Commit `4d2c15f` adds those exact text patches and their existing SHA-512
entries to the public snapshot. All libcamera aport inputs then passed checksum
verification, the package had already built successfully as `r12`, 139 project
tests passed with one private-environment skip, and the public tree validator
passed.

The boot, DTBO, kernel APK and raw/compressed rootfs payload hashes remain the
ones recorded in [Alpha 2 validation](2026-08-25-v0.1.0-alpha.2.md). Alpha 3
regenerates `SHA256SUMS`, `MANIFEST.md` and the versioned filenames under its
own tag. No phone partition was written for this provenance correction.
