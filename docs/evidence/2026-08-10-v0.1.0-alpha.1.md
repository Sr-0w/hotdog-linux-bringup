## Installation result

Bootloader fastboot identified the target as an unlocked `msmnile` device. A
direct bootloader `super` transfer using its advertised large segment size
stopped responding after the first segment. No release procedure uses that
path.

The validated path entered fastbootd from the preserved recovery slot and used:

```bash
fastboot -S 128M flash super oneplus-hotdog.img
```

Fastbootd wrote all 30 sparse segments successfully in 68.806 seconds. The
matching 100,663,296-byte AVB image was then written to `boot_b`, and slot B was
selected.

## Boot result

The first direct boot exposed USB networking after eight seconds and SSH shortly
afterward. The running command line contained the release UUID pair, `/` was
mounted from `/dev/loop0p2`, `/boot` from `/dev/loop0p1`, and Plasma had an
active seat session.

| Cycle | Boot ID | Result |
|---|---|---|
| Initial release boot | `2e81fa90-6449-41d1-8adb-ba69c5e7dffd` | Plasma, USB networking and SSH ready |
| Normal software reboot | `26a7add9-895b-4474-abcf-6026d3232396` | Returned to the same release in 28 seconds |

Neither validated boot enumerated as Qualcomm `900e`. Reboot-to-bootloader is a
separate unsupported restart-reason path and is not claimed by this release.
